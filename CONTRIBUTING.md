# Contribuir a Colora

Gracias por ayudar a mejorar Colora. Puedes abrir un issue para describir un error o proponer una idea antes de empezar un cambio grande.

## Preparar el proyecto

1. Instala Node.js 22.12 o superior.
2. Ejecuta `npm ci` y después `npm run dev`.
3. Crea una rama para tu cambio.
4. Antes de abrir un pull request, ejecuta `npm test` y `npm run build`.

En un reporte de error, incluye los pasos para reproducirlo, el resultado esperado y el navegador utilizado. Una captura puede ayudar en problemas visuales.

## Ilustraciones

Cada ilustración usa una imagen de líneas, una máscara de regiones y un archivo JSON con sus números y posiciones. Al modificarla, revisa que las áreas de fondo y los objetos tengan el color correcto, que los números sean legibles y que ninguna región quede inaccesible. Comprueba también la vista terminada y la descarga.

No incluyas credenciales, datos privados ni archivos locales de revisión en los commits. Las ilustraciones y el código aún no tienen una licencia de reutilización especificada; consulta al propietario antes de redistribuirlos.
